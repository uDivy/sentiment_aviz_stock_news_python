# sentiment_aviz_stock_news_python (https://www.youtube.com/watch?v=o-zM8onpQZY&t=2s)
This repo is for the python code used for the sentiment analysis of stock news.

Authors post about stocks on : https://finviz.com/

Objective : Using python to gather all the article titles, and use sentiment analysis to averaging 
            that the particular stocks is performing better or not, by understanding the title is positive or negative.

Technology used:
    Beautiful Soup : For Web Scraping ;
    Pandas : For analyze and run NLTK module for sentiment analysis ;
    Matplotlib : For Viz
